# CPU Process Scheduler

A simple C++ project that manages and schedules CPU processes.

## Features
- FCFS Scheduling
- SJF Scheduling
- Priority Scheduling
- Add, delete, update and search processes
- Sorting and filtering
- Heap visualization
- Waiting time and turnaround time calculation

## Technologies Used
- C++
- Data Structures and Algorithms

## How to Run
Compile the program:

```bash
g++ main.cpp -o scheduler
```

Run the program:

```bash
./scheduler
```
